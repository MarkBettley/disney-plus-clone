# Disney+ Clone

Aplicación web inspirada en Disney+ desarrollada como proyecto de Frontend.

El proyecto consume la API pública de TVMaze para mostrar contenido dinámico de películas y series mediante una interfaz inspirada en una plataforma de streaming.

## Funcionalidades

- Consumo de TVMaze API.
- Obtención dinámica de contenido.
- Visualización de películas y series.
- Consulta de programación de TV.
- Navegación entre página principal y sección de series.
- Interfaz responsive inspirada en Disney+.
- Manejo de solicitudes asíncronas.

## Tecnologías

- HTML5
- JavaScript
- Axios
- TVMaze API
- Sass / SCSS
- CSS3

## Estructura

- `index.html` - página principal.
- `series.html` - sección de series.
- `js/main.js` - lógica y consumo de API.
- `scss/` - estilos fuente en Sass.
- `css/` - estilos compilados.

## Uso

Clona el repositorio:

    git clone https://github.com/MarkBettley/disney-plus-clone.git

Abre `index.html` en un navegador.
